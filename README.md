# Sanath Kumar - Personal Portfolio

A sleek, modern, and fully responsive personal developer portfolio built to showcase my projects, skills, and experience.

## ✨ Features

- **Modern Glassmorphism UI**: Beautiful, semi-transparent components with smooth gradient backdrops.
- **Fully Responsive**: Scales perfectly on all devices (mobile, tablet, desktop).
- **Interactive Animations**: Hardware-accelerated scroll-reveal animations for a premium feel.
- **Dynamic Projects Showcase**: Highlighted sections for key projects (PulseGuard, Tabflow, Sentinel-CLI).
- **Skill Cloud**: A stylish tech stack showcase utilizing official Devicon and SimpleIcons SVGs.
- **Ajax Contact Form**: Fully integrated with Formspree for seamless, background message handling without page reloads.

## 🛠 Tech Stack

- **HTML5** & **CSS3** (Custom styling, CSS Variables, Flexbox/Grid)
- **Vanilla JavaScript** (DOM manipulation, scroll animations, Fetch API)
- **Boxicons** & **Devicon** (Typography and SVG iconography)
- **Formspree** (Form backend)

## 🚀 Getting Started

To run this portfolio locally on your machine:

1. Clone the repository:
   ```bash
   git clone https://github.com/sanathkmr14/portfolio.git
   ```
2. Navigate to the project directory:
   ```bash
   cd portfolio
   ```
3. Open `index.html` in your browser, or start a local development server (e.g. using Python):
   ```bash
   python3 -m http.server 8080
   ```
   Then visit `http://localhost:8080` in your browser.
